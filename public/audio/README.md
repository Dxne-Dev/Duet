# Dossier Audio

Déposez ici vos fichiers instrumentaux (beats sans voix) au format MP3 ou WAV.

Exemple :
- `public/audio/minuit-zero.mp3`
- `public/audio/coeur-laser.mp3`
- `public/audio/sans-reseau.mp3`
- `public/audio/dernier-metro.mp3`

Ces fichiers seront automatiquement accessibles sur l'URL `/audio/nom-du-fichier.mp3`.
