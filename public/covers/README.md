# Dossier Pochettes (Covers)

Déposez ici les images de pochettes d'albums (format JPG, PNG ou WebP).

Exemple :
- `public/covers/minuit-zero.jpg`
- `public/covers/coeur-laser.jpg`
- `public/covers/sans-reseau.jpg`
- `public/covers/dernier-metro.jpg`

Ces images seront accessibles directement sur l'URL `/covers/nom-du-fichier.jpg`.
